# Hunt — Reselling / Sourcing Service

A website for a service that tracks down hard-to-get items (sold out, scalped, or stock-shorted)
on behalf of customers. Customers are only charged when the item is actually secured — the item's
price plus a one-time service fee between $0 and $100. If the item is never found, the customer
pays nothing.

## Tech

Zero-dependency, no-build static site — plain HTML, hand-written CSS, and a vanilla-JS single-page
app with a hash router. Runs by serving the `site/` folder or opening `site/index.html`.
